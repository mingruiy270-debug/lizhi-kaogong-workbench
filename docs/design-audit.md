# 设计审计

## 模式

重构类型：功能完整迁移，视觉全面重建，信息架构保持稳定。

Design Read：面向长期备考者的本地桌面学习产品，可信、专注、高信息密度，采用 Fluent UI 产品语言。

- `DESIGN_VARIANCE: 4`
- `MOTION_INTENSITY: 3`
- `VISUAL_DENSITY: 7`

## 保留

- 左侧学习/管理双分组导航。
- 首页、训练、复习、模考、知识、规律、诊断、AI、环境和设置的路由心智模型。
- 深绿沉浸式侧栏和灼橙主要动作。
- 内容、用户数据、AI 与 Obsidian 集成相互隔离。
- 键盘操作、空状态、降级提示和可解释的学习规则。

## 改进

- 使用系统化 Fluent tokens，避免局部颜色和圆角漂移。
- 缩短大标题，提升有效信息首屏占比。
- 用网格和分组替代过多大卡片，降低视觉疲劳。
- 深色模式由全局主题控制，避免页面局部反色。
- 动效只用于导航、状态变化、反馈和布局过渡，尊重 reduced motion。
- 所有加载、空、错误、离线和未配置状态都有明确下一步。
- 知识库工坊使用高密度文件队列、真实进度、审核分栏和来源警告，避免把长任务伪装成一次性表单。
- 修复 FluentProvider 高度链：Provider、应用网格、侧栏和工作区均设置明确高度与 `min-height: 0`，主内容恢复鼠标滚轮滚动。

## 设计锁

- 基础：冷灰绿中性色。
- 唯一品牌强调色：灼橙 `#D65F35`。
- 深绿只作为导航基础面，不作为第二强调色。
- 语义成功/警告/错误色仅表达真实状态。
- 卡片圆角 12px，输入和按钮圆角 8px，弹窗圆角 14px。
- 页面可见文案禁止使用 em-dash 和 en-dash。
