## 已知问题修复目标

1. 显式 ID、alias 或内容签名映射到稳定题号，重命名文件不丢学习记录。
2. Vault 使用逐题 upsert，更新索引不会级联删除错题、收藏和笔记。
3. 模考和练习都保存完整题目快照，Vault 更新或切换后仍按会话创建时内容判定。
4. 申论方法或知识文档缺失时展示来源明确的空状态，不停留在无限加载。
5. AI 模型配置区分“已保存”和“已验证”，失败状态包含可操作信息。
6. 恢复前创建快照，恢复失败自动回到操作前数据库。
7. 跨 Vault 的同名显式 ID 使用稳定目录命名空间隔离，避免串改题目与学习记录。
8. 远程模型要求 HTTPS、拒绝私网/回环、禁止重定向；本地模型只允许 loopback。
9. 模考倒计时归零自动交卷；主进程仍使用原子事务记录整场结果。

按用户实际工作习惯，飞书与 OpenClaw 不在新应用范围内，也不保留空入口。第三方授权、`.akvault` 解密与第三方品牌资产不属于 clean-room 产品能力。自动更新需要自有发布服务器和代码签名，当前交付采用可校验哈希的离线安装包，不伪装为已配置在线更新。
