## 主文案

我把自己的公考学习工作台开源了。

它不是一个必须把资料上传到云端的在线题库，而是一套运行在自己电脑上的私人学习系统：真题、讲义、错题、笔记和学习记录都可以由自己管理。

砺知考公工作台目前支持：

- 行测专项训练、自适应选题、错题复习和间隔复习
- 本地模考、断点续答、自动交卷和成绩分析
- 申论草稿、作答评估和学习诊断
- 可选的 AI 错题讲解与双阶段变式训练
- 自定义 Markdown 题库和多知识库切换
- 用 Microsoft MarkItDown 把 PDF、Word 等资料转成 Markdown
- 再由你自己配置的 LLM 整理、复核，人工确认后写入知识库

基础训练不依赖 AI，模型和 API Key 都由用户自己选择。项目不会附带来路不明的题库，也不会在后台自动上传整个知识库。

如果你也想拥有一个可迁移、可修改、不被平台锁定的私人公考工作台，欢迎试用、Star、提 Issue，或者一起完善它。
